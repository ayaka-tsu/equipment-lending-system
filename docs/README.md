# 備品貸出管理システム 設計ドキュメント

株式会社ノースブリッジ（架空の会社）向け「備品貸出管理システム」の仕様書一式です。
実装に着手する前に、担当 Issue に関係する文書を必ず読んでください。

## 文書一覧

| No    | 文書                                                                         | 内容                                                                                     |
| ----- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 01    | [要件定義書](01_requirements.md)                                             | 背景・目的・スコープ・業務フロー・機能要件・業務ルール                                   |
| 02    | [非機能要件定義書](02_non_functional_requirements.md)                        | 性能・セキュリティ・運用保守などの要件                                                   |
| 03    | [画面一覧・画面遷移](03_screen_list.md)                                      | 画面一覧、画面遷移図、全画面共通の仕様                                                   |
| 03-xx | [画面仕様書](screens/)                                                       | 画面ごとの詳細仕様（`SCR-xx_*.md`）                                                      |
| 04    | [ER図](04_er_diagram.md)                                                     | テーブル間のリレーション                                                                 |
| 05    | [テーブル定義書](05_table_definitions.md)                                    | カラム・制約・インデックス                                                               |
| 06    | [API設計書](06_api_design.md)                                                | API の共通仕様・エンドポイント一覧・エラーコード                                         |
| 06-a  | [OpenAPI 定義](api/openapi.yaml)                                             | API の詳細仕様（リクエスト／レスポンスのスキーマ）                                       |
| －    | [画面デザイン（Figma）](https://www.figma.com/design/1ObWsUfnxoIEvQl86inEBv) | 色・文字・共通部品・全画面のデザイン。画面の見た目はこちらを、動作は画面仕様書を正とする |

## 読む順番

1. 01 要件定義書 を通読して、業務と用語をつかむ
2. 担当 Issue に書かれた要件ID（`FR-xx` / `BR-xx` / `NFR-xx`）と画面ID（`SCR-xx`）をたどる
3. 画面仕様書 → API設計書・OpenAPI → テーブル定義書 の順に、実装に必要な箇所を読む

## ID の採番ルール

| 接頭辞     | 対象                       | 定義している文書    |
| ---------- | -------------------------- | ------------------- |
| `FR-xx`    | 機能要件                   | 01 要件定義書       |
| `BR-xx`    | 業務ルール                 | 01 要件定義書       |
| `NFR-X-xx` | 非機能要件（X は分類記号） | 02 非機能要件定義書 |
| `SCR-xx`   | 画面                       | 03 画面一覧         |
| `Q-xx`     | 未決事項                   | 01 要件定義書       |

Issue・PR・コードのコメントでは、この ID で仕様を参照してください（例：「BR-04 の重複申請チェックを実装」）。

## 仕様に疑問・誤りを見つけたら

- 実装者の判断で仕様を変えないでください。
- Issue に質問をコメントするか、「仕様確認」ラベルを付けた Issue を新しく立ててください。
- 仕様の変更は、この `docs/` を修正する PR で行います。変更したら各文書の改訂履歴も更新します。
