# ISSUE-05 備品詳細

| 項目     | 内容                                  |
| -------- | ------------------------------------- |
| 見積もり | 5h                                    |
| 前提     | ISSUE-04                              |
| 優先度   | Must                                  |
| ラベル   | `type:feature`, `area:api`, `area:ui` |

## 概要

備品1件の情報と貸出可能数を表示する。ここから貸出申請へ進む。

## 対象の仕様

- 機能要件：FR-11
- 業務ルール：BR-01、BR-10
- 画面：[SCR-04 備品詳細](../screens/SCR-04_equipment_detail.md)
- API：`GET /api/equipment/{equipmentId}`

## やること

- [ ] `GET /api/equipment/{equipmentId}` を実装する（`description`・`activeLoanCount`・`version` を含む）
- [ ] 削除済み・存在しない ID では 404 を返す
- [ ] SCR-04 の画面を作る（項目の表示、説明の改行をそのまま表示）
- [ ] 「貸出を申請する」ボタンの押せる・押せないを、状態と貸出可能数で切り替え、押せないときは理由を表示する

## 受入条件

- [ ] 貸出停止中の備品（シードの `PC-0003`）で、ボタンが押せず「この備品は貸出停止中のため申請できません。」と表示される
- [ ] 貸出可能数が0の備品で、ボタンが押せず「貸出可能な在庫がありません。」と表示される
- [ ] 存在しない ID（例：`/equipment/99999`）で 404 の画面が出る
- [ ] 説明の改行が画面でも改行として表示される

## 実装の手がかり

- 一覧と詳細で貸出可能数の計算が重複するので、ISSUE-04 で作った関数を使い回す。
- 「押せないボタン」は `disabled` にするだけでなく、理由を文章で出す（NFR-E-03）。

## この Issue でやらないこと

- 管理者向けの「現在の貸出状況」の表示（ISSUE-10）
- 「編集」ボタン（ISSUE-06）
- 貸出申請の画面（ISSUE-07）
