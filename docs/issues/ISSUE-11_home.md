# ISSUE-11 ホーム

| 項目     | 内容                      |
| -------- | ------------------------- |
| 見積もり | 5h                        |
| 前提     | ISSUE-08                  |
| 優先度   | Must                      |
| ラベル   | `type:feature`, `area:ui` |

## 概要

ログインした社員が、自分の貸出状況をひと目で確認できるようにする。延滞と返却期限間近を本人に気付かせることが目的。

## 対象の仕様

- 機能要件：FR-30
- 業務ルール：BR-06、BR-15
- 画面：[SCR-02 ホーム](../screens/SCR-02_home.md)
- API：`GET /api/me/loans`（ISSUE-08 で実装済み）

## やること

- [ ] SCR-02 の画面を作る（利用中の備品、手続き中の申請）
- [ ] 延滞があるとき赤、返却期限間近があるとき黄の警告を出す（件数付き）
- [ ] 承認済の申請があるときは「承認済の備品は総務部で受け取ってください。」を表示する
- [ ] 0件のときのメッセージを表示する
- [ ] 管理者には「承認待ちの申請が N 件あります」と申請・貸出管理への導線を出す

## 受入条件

- [ ] シードのデータでログインすると、延滞1件の赤い警告と、返却期限間近の黄色い警告が出る
- [ ] 延滞している備品の返却予定日が赤字で表示される
- [ ] 利用中の備品が0件の社員（例：`member7@example.com`）でログインすると、空のメッセージが表示され、エラーにならない
- [ ] 管理者でログインすると、承認待ちの件数が表示される

## 実装の手がかり

- 承認待ちの件数は、ISSUE-12 のダッシュボード API がまだない段階では `GET /api/loans?status=pending&perPage=1` の `pagination.totalCount` で取れる。ISSUE-12 を実装したらそちらに切り替えてよい。
- 表示の並び順は画面仕様のとおり（利用中は返却予定日の古い順、手続き中は申請日時の新しい順）。

## この Issue でやらないこと
