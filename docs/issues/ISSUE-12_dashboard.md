# ISSUE-12 管理ダッシュボード

| 項目     | 内容                                   |
| -------- | -------------------------------------- |
| 見積もり | 6h                                     |
| 前提     | ISSUE-10                               |
| 優先度   | **Should**（時間が足りなければ後回し） |
| ラベル   | `type:feature`, `area:api`, `area:ui`  |

## 概要

管理者が、対応すべき件数と全体の貸出状況をひと目で把握できるようにする。集計を SQL で書く練習も兼ねる。

## 対象の仕様

- 機能要件：FR-31
- 業務ルール：BR-06
- 画面：[SCR-08 管理ダッシュボード](../screens/SCR-08_admin_dashboard.md)
- API：`GET /api/dashboard`

## やること

- [ ] `GET /api/dashboard`（管理者のみ）を実装する
  - [ ] 件数：承認待ち・受取待ち・貸出中・延滞
  - [ ] カテゴリ別：保有数合計、貸出中の件数（備品が0件のカテゴリも0として返す）
- [ ] SCR-08 の画面を作る（件数カード、延滞の上位5件、カテゴリ別の表）
- [ ] 件数カードから、条件付きで申請・貸出管理へ遷移する
- [ ] 貸出率を計算して表示する（小数点以下切り捨て。保有数が0なら `－`）

## 受入条件

- [ ] 件数カードの数が、申請・貸出管理一覧を同じ条件で絞り込んだ件数と一致する
- [ ] 延滞が1件以上あるとき、延滞カードが赤で表示される
- [ ] 備品が1件もないカテゴリも行として表示され、貸出率が `－` になる
- [ ] 承認待ちカードをクリックすると、申請・貸出管理が「申請中」で絞り込まれた状態で開く
- [ ] 集計の SQL がカテゴリごとのループになっていない（1〜2回のクエリで取れている）

## 実装の手がかり

- 件数は `GROUP BY status` で一度に取れる。
- カテゴリ別は `categories` を起点に `LEFT JOIN` する（備品が0件のカテゴリを落とさないため）。
- 貸出率の計算で 0 除算にならないよう、保有数が0の場合を先に分ける。

## この Issue でやらないこと

- グラフの描画（表で十分）
