# SCR-01 ログイン

| 項目       | 内容                   |
| ---------- | ---------------------- |
| 画面ID     | SCR-01                 |
| URL        | `/login`               |
| 対象ロール | 未ログインの利用者     |
| 関連要件   | FR-01、BR-17、NFR-S-05 |
| 使用 API   | `POST /api/auth/login` |

## 概要

メールアドレスとパスワードでログインする。共通ヘッダーは表示しない。

## レイアウト

```
            備品貸出管理システム

  ┌ セッション切れのお知らせ（reason=expired のときだけ） ┐

  メールアドレス 必須
  [                                   ]
  パスワード 必須
  [                                   ]

  （ログイン失敗時のエラーメッセージ）

               [ ログイン ]
```

## 入力項目

| 項目           | 入力形式                                             | 必須 | チェック内容     | エラーメッセージ                       |
| -------------- | ---------------------------------------------------- | ---- | ---------------- | -------------------------------------- |
| メールアドレス | `type="email"`、`autocomplete="username"`            | ○    | 未入力           | メールアドレスを入力してください       |
|                |                                                      |      | 形式が正しくない | メールアドレスの形式が正しくありません |
| パスワード     | `type="password"`、`autocomplete="current-password"` | ○    | 未入力           | パスワードを入力してください           |

## 操作

| 操作                                        | 動作                                                                                                                         |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 「ログイン」ボタン（または Enter キー）     | 入力チェックのあと `POST /api/auth/login` を呼ぶ。                                                                           |
| API が 200 を返した                         | ホーム（`/`）へ移動する。                                                                                                    |
| API が 401（`INVALID_CREDENTIALS`）を返した | フォームの下に「メールアドレスまたはパスワードが正しくありません」と表示し、パスワード欄を空にする。メールアドレス欄は残す。 |

## 補足

- URL に `?reason=expired` が付いているときは、フォームの上に「セッションの有効期限が切れました。再度ログインしてください。」と表示する。
- ログイン済みの利用者がこの画面を開いた場合は、ホームへリダイレクトする。
- どちらの項目が誤っているかを区別するメッセージは出さない（BR-17）。
