# SCR-02 ホーム

| 項目       | 内容                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------ |
| 画面ID     | SCR-02                                                                                           |
| URL        | `/`                                                                                              |
| 対象ロール | 全員                                                                                             |
| 関連要件   | FR-30、BR-06、BR-15                                                                              |
| 使用 API   | `GET /api/me/loans?status=pending,approved,lent&perPage=100`、`GET /api/dashboard`（管理者のみ） |

## 概要

ログインした社員が、自分の貸出状況をひと目で確認するための画面。延滞や返却期限間近の備品があれば警告する。

## レイアウト

```
[共通ヘッダー]

 ┌ 管理者メニュー（管理者のみ） ─────────────────────────┐
 │ 承認待ちの申請が 3 件あります  [申請・貸出管理へ]           │
 └────────────────────────────────────────────┘

 ┌ 警告（延滞があるとき：赤） ──────────────────────────┐
 │ 返却予定日を過ぎている備品が 1 件あります。至急返却してください。 │
 └────────────────────────────────────────────┘
 ┌ 注意（返却期限間近があるとき：黄） ─────────────────────┐
 │ 返却予定日が近い備品が 2 件あります。                        │
 └────────────────────────────────────────────┘

 利用中の備品
 | 管理番号 | 備品名 | 返却予定日 | 状態 |          |
 | PC-0003  | ノートPC（14インチ） | 2026/09/10 | [延滞] | [詳細] |

 手続き中の申請
 | 申請日 | 管理番号 | 備品名 | 返却予定日 | 状態 |          |
 | 2026/09/12 | BK-0012 | リーダブルコード | 2026/09/26 | [承認済] | [詳細] |
   ※ 承認済の申請があるとき：「承認済の備品は総務部で受け取ってください。」

 [備品を探す]  [申請履歴をすべて見る]
```

## 表示項目

### 管理者メニュー（管理者のみ）

| 項目                 | 内容                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------- |
| 承認待ちの件数       | `GET /api/dashboard` の `counts.pending`。0件のときは「承認待ちの申請はありません」と表示する。 |
| 「申請・貸出管理へ」 | `/admin/loans?status=pending` へ移動する。                                                      |

### 警告

| 種類               | 表示条件                                              | メッセージ                                                        |
| ------------------ | ----------------------------------------------------- | ----------------------------------------------------------------- |
| 延滞（赤）         | 取得した申請に `isOverdue = true` のものが1件以上ある | 返却予定日を過ぎている備品が N 件あります。至急返却してください。 |
| 返却期限間近（黄） | 取得した申請に `isDueSoon = true` のものが1件以上ある | 返却予定日が近い備品が N 件あります。                             |

どちらもないときは表示しない。

### 利用中の備品

ステータスが `lent` の申請を、返却予定日の古い順に表示する。

| 列         | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 管理番号   | `equipment.assetCode`                                |
| 備品名     | `equipment.name`。クリックすると SCR-04 へ移動する。 |
| 返却予定日 | `dueDate`                                            |
| 状態       | バッジ（貸出中／延滞）                               |
| 詳細       | SCR-07 へ移動する。                                  |

0件のときは「現在利用中の備品はありません」と表示する。

### 手続き中の申請

ステータスが `pending`・`approved` の申請を、申請日時の新しい順に表示する。

| 列         | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 申請日     | `createdAt`（日付のみ）                              |
| 管理番号   | `equipment.assetCode`                                |
| 備品名     | `equipment.name`。クリックすると SCR-04 へ移動する。 |
| 返却予定日 | `dueDate`                                            |
| 状態       | バッジ（申請中／承認済）                             |
| 詳細       | SCR-07 へ移動する。                                  |

- 0件のときは「手続き中の申請はありません」と表示する。
- `approved` の申請が1件以上あるときは、表の下に「承認済の備品は総務部で受け取ってください。」と表示する。

## 操作

| 操作                     | 動作                |
| ------------------------ | ------------------- |
| 「備品を探す」           | SCR-03 へ移動する。 |
| 「申請履歴をすべて見る」 | SCR-06 へ移動する。 |

## 補足

- 1人の社員が同時に持つ未完了の申請は通常数件のため、`perPage=100` で1回取得すれば足りる前提とする（ページングしない）。
