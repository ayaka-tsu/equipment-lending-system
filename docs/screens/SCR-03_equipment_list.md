# SCR-03 備品一覧

| 項目       | 内容                                        |
| ---------- | ------------------------------------------- |
| 画面ID     | SCR-03                                      |
| URL        | `/equipment`                                |
| 対象ロール | 全員                                        |
| 関連要件   | FR-10、BR-01、BR-10                         |
| 使用 API   | `GET /api/categories`、`GET /api/equipment` |

## 概要

備品を検索して一覧表示する。社員が「借りたい物が空いているか」を自分で確認できるようにする（課題2の解消）。

## レイアウト

```
[共通ヘッダー]

 備品一覧                                              [＋ 備品を登録] ※管理者のみ

 キーワード [                    ]  カテゴリ [すべて     ▼]  □ 貸出可能なもののみ
 [検索] [クリア]

 全 123 件中 1〜20 件
 | 管理番号 | 備品名               | カテゴリ | 保管場所             | 貸出可能数 | 状態       |
 | BK-0012  | リーダブルコード      | 書籍     | 本社3F 書棚A          | 2 / 3      |            |
 | MN-0004  | 27インチモニター      | モニター | 本社3F 総務キャビネット | 0 / 1      | [在庫なし] |
 | PC-0003  | ノートPC（14インチ）  | PC       | 本社3F 総務キャビネット | 0 / 1      | [貸出停止] |

 [< 前へ]  1 / 7  [次へ >]
```

## 入力項目（検索条件）

| 項目               | 入力形式                | URL クエリ           | 内容                                                                                   |
| ------------------ | ----------------------- | -------------------- | -------------------------------------------------------------------------------------- |
| キーワード         | テキスト（最大100文字） | `q`                  | 備品名または管理番号の部分一致。大文字・小文字を区別しない。                           |
| カテゴリ           | セレクトボックス        | `categoryId`         | 先頭に「すべて」を置き、続けて `GET /api/categories` の結果を `sortOrder` 順に並べる。 |
| 貸出可能なもののみ | チェックボックス        | `availableOnly=true` | オンのとき、状態が `active` かつ貸出可能数が1以上の備品だけを表示する。                |

## 表示項目

| 列         | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 管理番号   | `assetCode`                                          |
| 備品名     | `name`。クリックすると SCR-04 へ移動する。           |
| カテゴリ   | `category.name`                                      |
| 保管場所   | `storageLocation`                                    |
| 貸出可能数 | `availableQuantity / quantity` の形式（例：`2 / 3`） |
| 状態       | 共通仕様 3.4「備品の状態」のバッジ                   |

- 並び順は管理番号の昇順。
- 削除した備品は表示しない。
- 0件のときは「条件に一致する備品はありません」と表示する。

## 操作

| 操作                            | 動作                                                     |
| ------------------------------- | -------------------------------------------------------- |
| 「検索」                        | 入力した条件を URL クエリに反映し、1ページ目を表示する。 |
| 「クリア」                      | 検索条件をすべて消し、`/equipment` を表示する。          |
| 「＋ 備品を登録」（管理者のみ） | SCR-10 へ移動する。                                      |
| 「前へ」「次へ」                | 検索条件を保ったまま、ページを移動する（`page`）。       |

## 補足

- URL クエリの値が不正（例：`page=abc`）で API が 422 を返した場合は、条件なしの一覧（`/equipment`）へ置き換える。
