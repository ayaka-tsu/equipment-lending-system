# SCR-04 備品詳細

| 項目       | 内容                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 画面ID     | SCR-04                                                                                                                                |
| URL        | `/equipment/[equipmentId]`                                                                                                            |
| 対象ロール | 全員（「現在の貸出状況」は管理者のみ）                                                                                                |
| 関連要件   | FR-11、BR-01、BR-10                                                                                                                   |
| 使用 API   | `GET /api/equipment/{equipmentId}`、`GET /api/loans?equipmentId={equipmentId}&status=pending,approved,lent&perPage=100`（管理者のみ） |

## 概要

備品の情報と貸出可能数を表示し、貸出申請へ進む入口になる。管理者には、その備品を今だれが借りているか・申請しているかを表示する（課題1の解消）。

## レイアウト

```
[共通ヘッダー]

 < 備品一覧へ戻る

 ノートPC（14インチ）  [貸出停止]                                  [編集] ※管理者のみ

 管理番号     PC-0003
 カテゴリ     PC
 保管場所     本社3F 総務キャビネット
 保有数       1
 貸出可能数   0
 説明         Windows 11 / メモリ16GB
              充電器・マウス付き
 最終更新     2026/09/10 18:22

 [貸出を申請する]   ← 押せないときは理由を表示

 現在の貸出状況（管理者のみ）
 | 申請番号 | 申請者             | 状態     | 返却予定日 | 申請日     |
 | #118     | 山田 太郎（開発部） | [貸出中] | 2026/09/20 | 2026/09/05 |
```

## 表示項目

| 項目       | 内容                                                     |
| ---------- | -------------------------------------------------------- |
| 備品名     | `name`                                                   |
| 状態バッジ | 共通仕様 3.4「備品の状態」                               |
| 管理番号   | `assetCode`                                              |
| カテゴリ   | `category.name`                                          |
| 保管場所   | `storageLocation`                                        |
| 保有数     | `quantity`                                               |
| 貸出可能数 | `availableQuantity`                                      |
| 説明       | `description`。未設定なら `－`。改行はそのまま表示する。 |
| 最終更新   | `updatedAt`（日時）                                      |

### 現在の貸出状況（管理者のみ）

| 列         | 内容                                      |
| ---------- | ----------------------------------------- |
| 申請番号   | `#id`。クリックすると SCR-07 へ移動する。 |
| 申請者     | `borrower.name`（`borrower.department`）  |
| 状態       | バッジ（申請中／承認済／貸出中／延滞）    |
| 返却予定日 | `dueDate`                                 |
| 申請日     | `createdAt`（日付のみ）                   |

- 並び順は申請日時の新しい順。
- 0件のときは「現在、この備品の申請・貸出はありません」と表示する。

## 操作

| 操作                   | 動作                |
| ---------------------- | ------------------- |
| 「備品一覧へ戻る」     | SCR-03 へ移動する。 |
| 「貸出を申請する」     | SCR-05 へ移動する。 |
| 「編集」（管理者のみ） | SCR-11 へ移動する。 |

### 「貸出を申請する」ボタンの状態

| 条件                                            | ボタン   | ボタンの下に表示するメッセージ             |
| ----------------------------------------------- | -------- | ------------------------------------------ |
| `status` が `suspended`                         | 押せない | この備品は貸出停止中のため申請できません。 |
| `status` が `active` で `availableQuantity` が0 | 押せない | 貸出可能な在庫がありません。               |
| 上記以外                                        | 押せる   | －                                         |

同じ備品を既に申請している場合（BR-04）の判定は、申請時に API が行う（SCR-05）。

## エラー時の動作

| 状況                                        | 動作                      |
| ------------------------------------------- | ------------------------- |
| API が 404 を返した（存在しない・削除済み） | SCR-90（404）を表示する。 |
