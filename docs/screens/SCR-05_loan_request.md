# SCR-05 貸出申請

| 項目       | 内容                                                  |
| ---------- | ----------------------------------------------------- |
| 画面ID     | SCR-05                                                |
| URL        | `/equipment/[equipmentId]/request`                    |
| 対象ロール | 全員                                                  |
| 関連要件   | FR-20、BR-01〜05、BR-10、BR-18                        |
| 使用 API   | `GET /api/equipment/{equipmentId}`、`POST /api/loans` |

## 概要

返却予定日と利用目的を入力して、備品の貸出を申請する。

## レイアウト

```
[共通ヘッダー]

 貸出申請

 ┌ 申請する備品 ─────────────────────┐
 │ PC-0003  ノートPC（14インチ）              │
 │ 保管場所：本社3F 総務キャビネット          │
 │ 貸出可能数：1                              │
 └───────────────────────────┘

 （API のエラーメッセージ表示領域）

 返却予定日 必須
 [2026/09/20  📅]   翌日から30日後まで選べます

 利用目的 必須
 [                                              ]
 [                                              ]
                                        12 / 200

 [申請する]  [キャンセル]
```

## 入力項目

| 項目       | 入力形式                                                                | 必須 | チェック内容             | エラーメッセージ                                       |
| ---------- | ----------------------------------------------------------------------- | ---- | ------------------------ | ------------------------------------------------------ |
| 返却予定日 | `type="date"`。`min` に翌日、`max` に30日後を設定する（日本時間で計算） | ○    | 未入力                   | 返却予定日を入力してください                           |
|            |                                                                         |      | 翌日〜30日後の範囲外     | 返却予定日は明日から30日後までの日付を指定してください |
| 利用目的   | テキストエリア（3行）。入力中の文字数を「N / 200」で表示する            | ○    | 未入力（空白のみを含む） | 利用目的を入力してください                             |
|            |                                                                         |      | 200文字を超える          | 利用目的は200文字以内で入力してください                |

利用目的の例をプレースホルダーに表示する：「例：9/15〜の客先常駐で使用するため」

## 操作

| 操作                | 動作                                                                                                        |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| 「申請する」        | 確認ダイアログは出さずに `POST /api/loans` を呼ぶ（申請は本人が取り消せるため）。                           |
| API が 201 を返した | SCR-07（`/loans/{作成された申請のid}`）へ移動し、「貸出を申請しました。承認をお待ちください。」を表示する。 |
| 「キャンセル」      | SCR-04 へ戻る。                                                                                             |

## 表示条件

画面を開いたときに備品を取得し、次の場合はフォームを押せない状態にして、理由を表示する。

| 条件                    | 表示するメッセージ                         |
| ----------------------- | ------------------------------------------ |
| `status` が `suspended` | この備品は貸出停止中のため申請できません。 |
| `availableQuantity` が0 | 貸出可能な在庫がありません。               |

## エラー時の動作

画面を開いたあとに他の社員が申請して在庫がなくなる場合があるため、最終的な判定は API で行う（BR-02）。

| API の応答                  | 表示するメッセージ（API の `error.message`）                       |
| --------------------------- | ------------------------------------------------------------------ |
| 409 `OUT_OF_STOCK`          | 貸出可能な在庫がありません。                                       |
| 409 `DUPLICATE_ACTIVE_LOAN` | この備品は既に申請中または貸出中です。申請履歴を確認してください。 |
| 409 `EQUIPMENT_SUSPENDED`   | この備品は貸出停止中のため申請できません。                         |
| 422 `VALIDATION_ERROR`      | 各項目の下に `details` のメッセージを表示する。                    |
| 404                         | SCR-90（404）を表示する。                                          |

409 のときは入力内容を残したまま、画面上部にメッセージを表示する。
