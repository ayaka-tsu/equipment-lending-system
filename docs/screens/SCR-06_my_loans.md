# SCR-06 申請履歴

| 項目       | 内容                |
| ---------- | ------------------- |
| 画面ID     | SCR-06              |
| URL        | `/my/loans`         |
| 対象ロール | 全員                |
| 関連要件   | FR-21               |
| 使用 API   | `GET /api/me/loans` |

## 概要

ログインしている社員自身の申請を、状態別のタブで一覧表示する。

## レイアウト

```
[共通ヘッダー]

 申請履歴

 [すべて] [手続き中] [貸出中] [完了]

 全 14 件中 1〜14 件
 | 申請番号 | 申請日     | 管理番号 | 備品名               | 返却予定日 | 状態     |        |
 | #131     | 2026/09/12 | BK-0012  | リーダブルコード      | 2026/09/26 | [承認済] | [詳細] |
 | #118     | 2026/09/05 | PC-0003  | ノートPC（14インチ）  | 2026/09/20 | [貸出中] | [詳細] |
 | #097     | 2026/08/20 | MN-0004  | 27インチモニター      | 2026/08/31 | [却下]   | [詳細] |

 [< 前へ]  1 / 1  [次へ >]
```

## タブ

| タブ               | URL クエリ        | API に渡す `status`           |
| ------------------ | ----------------- | ----------------------------- |
| すべて（初期表示） | `tab` なし        | 指定しない                    |
| 手続き中           | `tab=in_progress` | `pending,approved`            |
| 貸出中             | `tab=lent`        | `lent`                        |
| 完了               | `tab=done`        | `returned,rejected,cancelled` |

タブを切り替えたら1ページ目に戻す。

## 表示項目

| 列         | 内容                                     |
| ---------- | ---------------------------------------- |
| 申請番号   | `#id`                                    |
| 申請日     | `createdAt`（日付のみ）                  |
| 管理番号   | `equipment.assetCode`                    |
| 備品名     | `equipment.name`                         |
| 返却予定日 | `dueDate`                                |
| 状態       | 共通仕様 3.4「申請のステータス」のバッジ |
| 詳細       | SCR-07 へ移動する。                      |

- 並び順は申請日時の新しい順。
- 0件のときは「該当する申請はありません」と表示する。

## 操作

| 操作             | 動作                         |
| ---------------- | ---------------------------- |
| タブ             | 表示する申請を切り替える。   |
| 「詳細」         | SCR-07 へ移動する。          |
| 「前へ」「次へ」 | ページを移動する（`page`）。 |

申請の取消は SCR-07 で行う。
