# SCR-07 申請詳細

| 項目       | 内容                                                                                                                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 画面ID     | SCR-07                                                                                                                                                                                                  |
| URL        | `/loans/[loanId]`                                                                                                                                                                                       |
| 対象ロール | 申請者本人、管理者                                                                                                                                                                                      |
| 関連要件   | FR-22〜27、BR-07〜09、BR-16、NFR-S-07                                                                                                                                                                   |
| 使用 API   | `GET /api/loans/{loanId}`、`POST /api/loans/{loanId}/approve`、`POST /api/loans/{loanId}/reject`、`POST /api/loans/{loanId}/cancel`、`POST /api/loans/{loanId}/lend`、`POST /api/loans/{loanId}/return` |

## 概要

申請の内容と処理の経過を表示する。申請に対するすべての状態変更（取消・承認・却下・貸出記録・返却記録）は、この画面から行う。

## レイアウト

```
[共通ヘッダー]

 申請 #118  [貸出中]

 （操作ボタン：表示できるものだけ並べる）
 [承認する] [却下する] [貸出を記録する] [返却を記録する] [申請を取り消す]

 ┌ 申請内容 ─────────────────────────────┐
 │ 備品         PC-0003 ノートPC（14インチ）  ← SCR-04 へのリンク │
 │ 申請者       山田 太郎（E0012 / 開発部）                    │
 │ 申請日時     2026/09/05 10:12                              │
 │ 返却予定日   2026/09/20                                    │
 │ 利用目的     客先常駐で使用するため                          │
 └────────────────────────────────────┘

 ┌ 処理の経過 ───────────────────────────┐
 │ 2026/09/05 10:12  申請                  山田 太郎          │
 │ 2026/09/05 13:40  承認                  佐藤 花子          │
 │ 2026/09/06 09:05  貸出                                     │
 │                   返却（未）                               │
 └────────────────────────────────────┘
```

## 表示項目

### 見出し

| 項目     | 内容                                     |
| -------- | ---------------------------------------- |
| 申請番号 | `申請 #id`                               |
| 状態     | 共通仕様 3.4「申請のステータス」のバッジ |

### 申請内容

| 項目       | 内容                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 備品       | `equipment.assetCode` と `equipment.name`。クリックすると SCR-04 へ移動する。                          |
| 申請者     | `borrower.name`（`borrower.employeeCode` / `borrower.department`）                                     |
| 申請日時   | `createdAt`                                                                                            |
| 返却予定日 | `dueDate`。延滞のときは赤字にして「（N日超過）」を付ける。N は今日（日本時間）と返却予定日の差の日数。 |
| 利用目的   | `purpose`                                                                                              |
| 却下理由   | `rejectReason`。ステータスが `rejected` のときだけ表示する。                                           |

### 処理の経過

発生したものだけを、時刻の古い順に表示する。

| 行   | 日時          | 担当者             | 表示条件                                    |
| ---- | ------------- | ------------------ | ------------------------------------------- |
| 申請 | `createdAt`   | `borrower.name`    | 常に                                        |
| 承認 | `reviewedAt`  | `reviewedBy.name`  | ステータスが `approved`・`lent`・`returned` |
| 却下 | `reviewedAt`  | `reviewedBy.name`  | ステータスが `rejected`                     |
| 貸出 | `lentAt`      | －                 | `lentAt` がある                             |
| 返却 | `returnedAt`  | －                 | `returnedAt` がある                         |
| 取消 | `cancelledAt` | `cancelledBy.name` | ステータスが `cancelled`                    |

貸出・返却を記録した管理者は、操作履歴（SCR-12）で確認する。

## 操作

### 表示するボタン

**API が返す `allowedActions`（ログイン中の利用者が今この申請に実行できる操作）に含まれるボタンだけを表示する。** 画面側で状態遷移表（BR-07）を再実装しない。

| `allowedActions` の値 | ボタン         | 確認ダイアログの文言                                                     | 実行ボタン | 呼ぶ API                           | 成功メッセージ         |
| --------------------- | -------------- | ------------------------------------------------------------------------ | ---------- | ---------------------------------- | ---------------------- |
| `approve`             | 承認する       | この申請を承認します。よろしいですか？                                   | 承認する   | `POST /api/loans/{loanId}/approve` | 申請を承認しました。   |
| `reject`              | 却下する       | （下記「却下ダイアログ」）                                               | 却下する   | `POST /api/loans/{loanId}/reject`  | 申請を却下しました。   |
| `lend`                | 貸出を記録する | 備品を申請者に渡したことを記録します。よろしいですか？                   | 記録する   | `POST /api/loans/{loanId}/lend`    | 貸出を記録しました。   |
| `return`              | 返却を記録する | 備品が返却されたことを記録します。よろしいですか？                       | 記録する   | `POST /api/loans/{loanId}/return`  | 返却を記録しました。   |
| `cancel`              | 申請を取り消す | この申請を取り消します。取り消した申請は元に戻せません。よろしいですか？ | 取り消す   | `POST /api/loans/{loanId}/cancel`  | 申請を取り消しました。 |

参考：`allowedActions` の中身は API が次のように決める（BR-07・08・16）。

| 状態               | 申請者本人（一般社員） | 管理者（他人の申請） | 管理者（自分の申請） |
| ------------------ | ---------------------- | -------------------- | -------------------- |
| 申請中             | `cancel`               | `approve`、`reject`  | `cancel`             |
| 承認済             | `cancel`               | `lend`、`cancel`     | `lend`、`cancel`     |
| 貸出中             | なし                   | `return`             | `return`             |
| 返却済・却下・取消 | なし                   | なし                 | なし                 |

### 却下ダイアログ

```
 申請を却下します
 却下理由 必須
 [                                    ]
                              0 / 200
 [却下する]  [キャンセル]
```

| 項目     | 必須 | チェック内容             | エラーメッセージ                        |
| -------- | ---- | ------------------------ | --------------------------------------- |
| 却下理由 | ○    | 未入力（空白のみを含む） | 却下理由を入力してください              |
|          |      | 200文字を超える          | 却下理由は200文字以内で入力してください |

### 成功したとき

画面を開き直さずに申請を再取得して表示を更新し、画面上部に成功メッセージを表示する。

## エラー時の動作

| 状況                                                                          | 動作                                                                                                       |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `GET` が 404 を返した（存在しない・他人の申請）                               | SCR-90（404）を表示する。                                                                                  |
| 操作が 409 `INVALID_STATUS_TRANSITION` を返した（他の管理者が先に処理した等） | 「この申請は他の操作によって状態が変わっています。最新の状態を表示しました。」を表示し、申請を再取得する。 |
| 操作が 403 `SELF_REVIEW_FORBIDDEN` を返した                                   | API の `error.message` を表示する（通常は `allowedActions` によりボタンが出ないため起きない）。            |
