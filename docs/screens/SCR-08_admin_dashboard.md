# SCR-08 管理ダッシュボード

| 項目       | 内容                                                          |
| ---------- | ------------------------------------------------------------- |
| 画面ID     | SCR-08                                                        |
| URL        | `/admin`                                                      |
| 対象ロール | 管理者                                                        |
| 関連要件   | FR-31、BR-06                                                  |
| 使用 API   | `GET /api/dashboard`、`GET /api/loans?overdue=true&perPage=5` |

## 概要

管理者が、今対応すべき申請と全体の貸出状況を把握するための画面。延滞を翌日には把握できるようにする（KPI 3）。

## レイアウト

```
[共通ヘッダー]

 管理ダッシュボード

 ┌ 承認待ち ┐ ┌ 受取待ち ┐ ┌ 貸出中 ┐ ┌ 延滞 ────┐
 │    3 件  │ │    1 件  │ │  42 件 │ │    2 件  │ ← 1件以上なら赤
 └──────┘ └──────┘ └─────┘ └──────┘

 延滞している貸出（返却予定日の古い順 5件）                    [すべて見る]
 | 申請番号 | 返却予定日 | 超過日数 | 申請者             | 備品                     |
 | #088     | 2026/09/01 | 12日     | 鈴木 一郎（営業部） | PC-0010 ノートPC（14インチ） |

 カテゴリ別の貸出状況
 | カテゴリ     | 保有数合計 | 貸出中 | 貸出率 |
 | PC           | 40         | 31     | 77%    |
 | モニター     | 25         | 8      | 32%    |
 | その他       | 0          | 0      | －     |
```

## 表示項目

### 件数カード

| カード   | 値                                          | クリックしたときの移動先       |
| -------- | ------------------------------------------- | ------------------------------ |
| 承認待ち | `counts.pending`                            | `/admin/loans?status=pending`  |
| 受取待ち | `counts.approved`                           | `/admin/loans?status=approved` |
| 貸出中   | `counts.lent`（延滞を含む）                 | `/admin/loans?status=lent`     |
| 延滞     | `counts.overdue`。1件以上なら赤で表示する。 | `/admin/loans?overdue=true`    |

### 延滞している貸出

`GET /api/loans?overdue=true&perPage=5` の結果（返却予定日の古い順）を表示する。

| 列         | 内容                                      |
| ---------- | ----------------------------------------- |
| 申請番号   | `#id`。クリックすると SCR-07 へ移動する。 |
| 返却予定日 | `dueDate`                                 |
| 超過日数   | 今日（日本時間）と返却予定日の差の日数    |
| 申請者     | `borrower.name`（`borrower.department`）  |
| 備品       | `equipment.assetCode` と `equipment.name` |

- 0件のときは「延滞している貸出はありません」と表示する。
- 「すべて見る」は `/admin/loans?overdue=true` へ移動する。

### カテゴリ別の貸出状況

`categories` を、カテゴリの表示順（`sortOrder`）で表示する。

| 列         | 内容                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| カテゴリ   | `categoryName`                                                                                          |
| 保有数合計 | `totalQuantity`（削除していない備品の保有数の合計。貸出停止中を含む）                                   |
| 貸出中     | `lentCount`（ステータスが `lent` の申請の件数）                                                         |
| 貸出率     | `lentCount ÷ totalQuantity × 100` の小数点以下を切り捨てて `%` を付ける。`totalQuantity` が0なら `－`。 |

備品が1件もないカテゴリも、0として表示する。
