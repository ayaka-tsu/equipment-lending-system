# SCR-09 申請・貸出管理

| 項目       | 内容             |
| ---------- | ---------------- |
| 画面ID     | SCR-09           |
| URL        | `/admin/loans`   |
| 対象ロール | 管理者           |
| 関連要件   | FR-28、BR-06     |
| 使用 API   | `GET /api/loans` |

## 概要

全社員の申請を検索・一覧表示する。承認待ちの処理や延滞の確認に使う。個々の申請への操作は SCR-07 で行う。

## レイアウト

```
[共通ヘッダー]

 申請・貸出管理

 状態 [すべて ▼]  □ 延滞のみ
 申請者 [          ]（氏名・社員番号）  備品 [          ]（備品名・管理番号）
 [検索] [クリア]

 全 57 件中 1〜20 件
 | 申請番号 | 申請日     | 申請者             | 備品                         | 返却予定日 | 状態     |        |
 | #131     | 2026/09/12 | 田中 美咲（開発部） | BK-0012 リーダブルコード      | 2026/09/26 | [申請中] | [詳細] |
 | #118     | 2026/09/05 | 山田 太郎（開発部） | PC-0003 ノートPC（14インチ）  | 2026/09/20 | [貸出中] | [詳細] |

 [< 前へ]  1 / 3  [次へ >]
```

## 入力項目（検索条件）

| 項目     | 入力形式                                                               | URL クエリ       | 内容                                                                                                  |
| -------- | ---------------------------------------------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------------- |
| 状態     | セレクトボックス（すべて／申請中／承認済／貸出中／返却済／却下／取消） | `status`         | 選んだステータスの申請だけを表示する。                                                                |
| 延滞のみ | チェックボックス                                                       | `overdue=true`   | オンのとき、延滞（BR-06）の申請だけを表示する。オンにしたら「状態」は「すべて」に戻して選べなくする。 |
| 申請者   | テキスト（最大50文字）                                                 | `borrowerQuery`  | 申請者の氏名または社員番号の部分一致。                                                                |
| 備品     | テキスト（最大100文字）                                                | `equipmentQuery` | 備品名または管理番号の部分一致。                                                                      |

## 表示項目

| 列         | 内容                                      |
| ---------- | ----------------------------------------- |
| 申請番号   | `#id`                                     |
| 申請日     | `createdAt`（日付のみ）                   |
| 申請者     | `borrower.name`（`borrower.department`）  |
| 備品       | `equipment.assetCode` と `equipment.name` |
| 返却予定日 | `dueDate`                                 |
| 状態       | 共通仕様 3.4「申請のステータス」のバッジ  |
| 詳細       | SCR-07 へ移動する。                       |

- 並び順：「延滞のみ」がオンのときは返却予定日の古い順、それ以外は申請日時の新しい順。
- 0件のときは「条件に一致する申請はありません」と表示する。

## 操作

| 操作             | 動作                                                     |
| ---------------- | -------------------------------------------------------- |
| 「検索」         | 入力した条件を URL クエリに反映し、1ページ目を表示する。 |
| 「クリア」       | 検索条件をすべて消し、`/admin/loans` を表示する。        |
| 「詳細」         | SCR-07 へ移動する。                                      |
| 「前へ」「次へ」 | 検索条件を保ったまま、ページを移動する（`page`）。       |

## 補足

- SCR-02・SCR-08 からは、`?status=pending` や `?overdue=true` を付けてこの画面へ移動してくる。URL クエリの値を検索フォームの初期値にする。
