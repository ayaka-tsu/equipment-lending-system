# SCR-10 備品登録

| 項目       | 内容                                         |
| ---------- | -------------------------------------------- |
| 画面ID     | SCR-10                                       |
| URL        | `/admin/equipment/new`                       |
| 対象ロール | 管理者                                       |
| 関連要件   | FR-12、BR-13、BR-14                          |
| 使用 API   | `GET /api/categories`、`POST /api/equipment` |

## 概要

備品を新しく登録する。

## レイアウト

```
[共通ヘッダー]

 備品登録

 管理番号 必須
 [PC-0041   ]   英大文字2〜4文字＋ハイフン＋数字4桁（例：PC-0001）。登録後は変更できません。

 備品名 必須
 [                                        ]

 カテゴリ 必須
 [選択してください ▼]

 保有数 必須
 [ 1 ]

 保管場所 必須
 [                                        ]   例：本社3F 総務キャビネット

 説明
 [                                        ]
 [                                        ]
                                   0 / 1000

 状態 必須
 (●) 通常  ( ) 貸出停止

 [登録する]  [キャンセル]
```

## 入力項目

| 項目     | API の項目        | 入力形式                           | 必須 | チェック内容                              | エラーメッセージ                                                              |
| -------- | ----------------- | ---------------------------------- | ---- | ----------------------------------------- | ----------------------------------------------------------------------------- |
| 管理番号 | `assetCode`       | テキスト                           | ○    | 未入力                                    | 管理番号を入力してください                                                    |
|          |                   |                                    |      | 形式（`^[A-Z]{2,4}-[0-9]{4}$`）に合わない | 管理番号は「英大文字2〜4文字-数字4桁」の形式で入力してください（例：PC-0001） |
|          |                   |                                    |      | 既に使われている（API で判定）            | この管理番号は既に使用されています                                            |
| 備品名   | `name`            | テキスト                           | ○    | 未入力（空白のみを含む）                  | 備品名を入力してください                                                      |
|          |                   |                                    |      | 100文字を超える                           | 備品名は100文字以内で入力してください                                         |
| カテゴリ | `categoryId`      | セレクトボックス                   | ○    | 未選択                                    | カテゴリを選択してください                                                    |
| 保有数   | `quantity`        | `type="number"`、`min=1`、`max=99` | ○    | 未入力                                    | 保有数を入力してください                                                      |
|          |                   |                                    |      | 1〜99の整数でない                         | 保有数は1〜99の整数で入力してください                                         |
| 保管場所 | `storageLocation` | テキスト                           | ○    | 未入力（空白のみを含む）                  | 保管場所を入力してください                                                    |
|          |                   |                                    |      | 100文字を超える                           | 保管場所は100文字以内で入力してください                                       |
| 説明     | `description`     | テキストエリア（4行）              | －   | 1000文字を超える                          | 説明は1000文字以内で入力してください                                          |
| 状態     | `status`          | ラジオボタン（初期値：通常）       | ○    | －                                        | －                                                                            |

- 文字列の前後の空白は取り除いてからチェック・保存する（サーバー側でも行う）。
- 説明が空のときは未設定（`null`）として送る。

## 操作

| 操作                | 動作                                                                       |
| ------------------- | -------------------------------------------------------------------------- |
| 「登録する」        | 入力チェックのあと `POST /api/equipment` を呼ぶ。                          |
| API が 201 を返した | SCR-04（登録した備品の詳細）へ移動し、「備品を登録しました。」を表示する。 |
| 「キャンセル」      | SCR-03 へ戻る。                                                            |

## エラー時の動作

| API の応答                      | 動作                                                             |
| ------------------------------- | ---------------------------------------------------------------- |
| 409 `ASSET_CODE_ALREADY_EXISTS` | 管理番号の下に「この管理番号は既に使用されています」を表示する。 |
| 422 `VALIDATION_ERROR`          | 各項目の下に `details` のメッセージを表示する。                  |
