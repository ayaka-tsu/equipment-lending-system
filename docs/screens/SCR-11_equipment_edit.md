# SCR-11 備品編集

| 項目       | 内容                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 画面ID     | SCR-11                                                                                                                                 |
| URL        | `/admin/equipment/[equipmentId]/edit`                                                                                                  |
| 対象ロール | 管理者                                                                                                                                 |
| 関連要件   | FR-13、FR-14、BR-11〜14                                                                                                                |
| 使用 API   | `GET /api/categories`、`GET /api/equipment/{equipmentId}`、`PATCH /api/equipment/{equipmentId}`、`DELETE /api/equipment/{equipmentId}` |

## 概要

備品の情報を変更する。備品の削除もこの画面で行う。

```

 カテゴリ 必須
```

## 入力項目

SCR-10 と同じ。ただし次の点が異なる。

| 項目     | 違い                                                          |
| -------- | ------------------------------------------------------------- |
| 管理番号 | 入力欄ではなく文字として表示する（BR-13）。API にも送らない。 |
| 保有数   | 横に「現在の引当数：N」を表示する。N は `activeLoanCount`。   |

画面を開いたときに `GET /api/equipment/{equipmentId}` で取得した値を初期値にする。取得した `version` は画面に表示せず保持しておき、更新時に送る。

## 操作

| 操作                   | 動作                                                                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「更新する」           | 入力チェックのあと、全項目と `version` を `PATCH /api/equipment/{equipmentId}` に送る。                                                                                         |
| API が 200 を返した    | SCR-04 へ移動し、「備品を更新しました。」を表示する。                                                                                                                           |
| 「キャンセル」         | SCR-04 へ戻る。                                                                                                                                                                 |
| 「この備品を削除する」 | 確認ダイアログ「「{備品名}」を削除します。削除した備品は一覧に表示されなくなります。よろしいですか？」を表示する。「削除する」で `DELETE /api/equipment/{equipmentId}` を呼ぶ。 |
| DELETE が 204 を返した | SCR-03 へ移動し、「備品を削除しました。」を表示する。                                                                                                                           |

## エラー時の動作

| API の応答                                 | 動作                                                                                                                                           |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 409 `EDIT_CONFLICT`                        | 画面上部に「他の管理者がこの備品を更新しました。画面を再読み込みして、最新の内容を確認してから編集してください。」を表示する。入力内容は残す。 |
| 409 `QUANTITY_BELOW_ACTIVE_LOANS`          | 保有数の下に API の `error.message`（例：「保有数は現在の引当数（1）以上にしてください」）を表示する。                                         |
| 409 `EQUIPMENT_HAS_ACTIVE_LOANS`（削除時） | 画面上部に「未完了の申請があるため、この備品は削除できません。」を表示する。                                                                   |
| 422 `VALIDATION_ERROR`                     | 各項目の下に `details` のメッセージを表示する。                                                                                                |
| 404                                        | SCR-90（404）を表示する。                                                                                                                      |
