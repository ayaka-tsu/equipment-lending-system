# SCR-12 操作履歴

| 項目       | 内容                  |
| ---------- | --------------------- |
| 画面ID     | SCR-12                |
| URL        | `/admin/audit-logs`   |
| 対象ロール | 管理者                |
| 関連要件   | FR-33、BR-14、BR-18   |
| 使用 API   | `GET /api/audit-logs` |

## 概要

誰が・いつ・何をしたかを検索して表示する。棚卸しで数が合わないときなどに、経緯を追うために使う（課題4の解消）。

## レイアウト

```
[共通ヘッダー]

 操作履歴

 期間 [2026/09/01 📅] 〜 [2026/09/13 📅]  操作 [すべて ▼]  操作者 [          ]
 [検索] [クリア]

 全 250 件中 1〜20 件
 | 日時             | 操作者    | 操作     | 対象                                  | 内容                   |
 | 2026/09/13 10:02 | 佐藤 花子 | 備品編集 | 備品 PC-0003 ノートPC（14インチ）       | 状態：通常 → 貸出停止   |
 | 2026/09/12 16:40 | 佐藤 花子 | 却下     | 申請 #130 MN-0004 27インチモニター      | 理由：在庫の予約済みのため |
 | 2026/09/12 09:15 | 田中 美咲 | 貸出申請 | 申請 #131 BK-0012 リーダブルコード      | 申請者：田中 美咲       |

 [< 前へ]  1 / 13  [次へ >]
```

## 入力項目（検索条件）

| 項目         | 入力形式               | URL クエリ   | 内容                                                                |
| ------------ | ---------------------- | ------------ | ------------------------------------------------------------------- |
| 期間（開始） | `type="date"`          | `from`       | この日の 0:00（日本時間）以降の操作を表示する。                     |
| 期間（終了） | `type="date"`          | `to`         | この日の 23:59:59（日本時間）までの操作を表示する（終了日を含む）。 |
| 操作         | セレクトボックス       | `action`     | 先頭に「すべて」、続けて下表の操作種別。                            |
| 操作者       | テキスト（最大50文字） | `actorQuery` | 操作者の氏名の部分一致。                                            |

| チェック内容         | エラーメッセージ                           |
| -------------------- | ------------------------------------------ |
| 開始日が終了日より後 | 開始日は終了日以前の日付を指定してください |

### 操作種別

| `action`           | 表示名   |
| ------------------ | -------- |
| `equipment.create` | 備品登録 |
| `equipment.update` | 備品編集 |
| `equipment.delete` | 備品削除 |
| `loan.request`     | 貸出申請 |
| `loan.approve`     | 承認     |
| `loan.reject`      | 却下     |
| `loan.cancel`      | 取消     |
| `loan.lend`        | 貸出記録 |
| `loan.return`      | 返却記録 |

## 表示項目

| 列     | 内容                   |
| ------ | ---------------------- |
| 日時   | `createdAt`            |
| 操作者 | `actor.name`           |
| 操作   | `action` の表示名      |
| 対象   | 下表のとおり組み立てる |
| 内容   | 下表のとおり組み立てる |

| 対象の種類                       | 「対象」列                                                                                                  | 「内容」列                                                                                                                  |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 備品（`targetType = equipment`） | 「備品 {detail.assetCode} {detail.name}」。SCR-04 へのリンクにする（削除済みの備品はリンク先で404になる）。 | 備品編集のときは、`detail.changes` の各項目を「{項目名}：{変更前} → {変更後}」の形で「、」区切りで並べる。それ以外は `－`。 |
| 申請（`targetType = loan`）      | 「申請 #{targetId} {detail.equipmentAssetCode} {detail.equipmentName}」。SCR-07 へのリンクにする。          | 却下のときは「理由：{detail.reason}」、それ以外は「申請者：{detail.borrowerName}」。                                        |

`detail.changes` の項目名は次のように表示する。

| キー              | 表示名   | 値の表示                                            |
| ----------------- | -------- | --------------------------------------------------- |
| `name`            | 備品名   | そのまま                                            |
| `category`        | カテゴリ | そのまま（カテゴリ名が入っている）                  |
| `quantity`        | 保有数   | そのまま                                            |
| `storageLocation` | 保管場所 | そのまま                                            |
| `description`     | 説明     | 50文字を超える部分は「…」で省略する。`null` は `－` |
| `status`          | 状態     | `active` は「通常」、`suspended` は「貸出停止」     |

- 並び順は日時の新しい順。
- 0件のときは「条件に一致する操作履歴はありません」と表示する。

## 操作

| 操作             | 動作                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| 「検索」         | 入力チェックのあと、条件を URL クエリに反映し、1ページ目を表示する。 |
| 「クリア」       | 検索条件をすべて消し、`/admin/audit-logs` を表示する。               |
| 「前へ」「次へ」 | 検索条件を保ったまま、ページを移動する（`page`）。                   |
