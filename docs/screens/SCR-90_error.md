# SCR-90 エラー

| 項目       | 内容                                                         |
| ---------- | ------------------------------------------------------------ |
| 画面ID     | SCR-90                                                       |
| URL        | （特定の URL を持たない。エラーが起きた URL のまま表示する） |
| 対象ロール | 全員                                                         |
| 関連要件   | FR-03、NFR-M-01、NFR-S-12                                    |
| 使用 API   | なし                                                         |

## 概要

ページが見つからない・権限がない・想定外のエラーが起きたときに表示する。ログインしている場合は共通ヘッダーを表示する。

## レイアウト

```
[共通ヘッダー]（ログインしている場合）

          404
   ページが見つかりません
   URL が正しいか確認してください。

          [ホームへ戻る]
```

## 表示内容

| 種類 | 見出し                               | 説明文                                                                         | HTTP ステータス |
| ---- | ------------------------------------ | ------------------------------------------------------------------------------ | --------------- |
| 404  | ページが見つかりません               | URL が正しいか確認してください。                                               | 404             |
| 403  | このページを表示する権限がありません | 管理者のみが利用できるページです。                                             | 403             |
| 500  | エラーが発生しました                 | 時間をおいて再度お試しください。問題が続く場合は総務部へお問い合わせください。 | 500             |

## 操作

| 操作             | 動作                      |
| ---------------- | ------------------------- |
| 「ホームへ戻る」 | ホーム（`/`）へ移動する。 |

## 補足

- 500 のときも、スタックトレースやエラーの詳細は表示しない（NFR-S-12）。詳細はサーバーログに出力する（NFR-M-01）。
